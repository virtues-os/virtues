# Plan — what we intend

**Prescriptive and temporary.** Designs for things being built. A plan is the
only document type here that expires: **when the thing ships, delete the
plan.** What remains is a record of what was built and a page in the manual,
not a document describing an intention that has since become a fact.

This directory exists because of that rule. `docs/` grew to 63 files because
nothing was ever removed from it. A plan that is never deleted ends up looking
like a description of the system, and people read it as one.

**These never publish.** Most of these plans describe work that may change or
never ship, so a reader outside the project should not treat them as
commitments.
