# Build docs

**These are requirements, and they stay in force.** They say what must be true
when you write code here: contracts, vocabularies, style, and the runbooks for
operations we perform ourselves. They are kept up to date instead of dated:
when the system changes, these change with it.

Read the ones that cover your area BEFORE you write. They exist because the
same mistakes kept recurring across sessions.

**These are never published.** They are instructions for whoever is building,
and they only make sense with the codebase open. `virtues.com/docs` is the manual, written
for people running a box; see [`docs/`](../../docs/).

This follows from the font file, not from a style preference, and it is why there are two serif tokens over one face: `--font-serif-ui` is the same file with its vertical metrics corrected, for serif set beside something that is not text. The serif fallback is a system stack on purpose after Lora was deleted 2026-09-16 — a downloadable fallback would be a second file fetched only to cover the short time before the first one loads. **Open question that only a human can resolve: nothing here records whether the Avenir license covers self-hosting**, so don't add weights, don't copy the files into another repo, and don't remove them either. |
