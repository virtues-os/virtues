---
title: Connecting your devices
description: Pick the device you'll pair with your Virtues server first - a Mac, a Windows PC or an iPhone.
updated: 2026-10-26
---

Pair your server with the device you'll use first. You can add the others
later, from the same pages.

- **[Mac](/docs/setup/devices/mac):** the Virtues desktop app, on macOS 26.2
  or later.
- **[Windows PC](/docs/setup/devices/windows):** the Virtues desktop app.
- **[iPhone](/docs/setup/devices/iphone):** the Virtues iPhone app.

A web browser on another machine can't pair with your server.
