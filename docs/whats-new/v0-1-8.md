Released 2026-09-18. [All changes since v0.1.7](https://github.com/virtues-os/virtues/compare/v0.1.7...v0.1.8)

```sh
sudo virtues upgrade --version v0.1.8
```

## New

- **Copy and try again.** You can copy any answer, and ask the last question again.
- **Rejoin a reply in progress.** If you leave a chat while your server is still answering, coming back picks the reply up where it is. If the reply never finished, the chat tells you.
- **Cheaper long chats.** Your server asks the AI provider to cache the start of each conversation, which it had never done. Most of a long chat's input is now read from the cache, at a fraction of the price.

## Changed

- **Chats panel.** The panel starts with New chat and Search chats.
- **Stop stops.** Pressing Stop ends the turn on your server, not just on screen.
- **Try again.** Try again rejoins a reply that's still running before it asks again, and each chat runs one turn at a time.

## Fixed

- Shortening a long chat no longer deletes the context it was told to keep.
- A file dropped on the composer attaches once, not twice. When the tray turns a file away, it says why.
- Switching conversations no longer carries the last one's state into the next.
- A temporary chat leaves nothing behind, including the permissions you gave it.
- A turn's tool calls and their arguments survive a reload.
- Adding a chat to a project makes it show up there.
- Your day's most unusual moments are ranked correctly again.
- Usage is charged to whoever actually paid for it: your subscription or your own AI endpoint.
