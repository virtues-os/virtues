Released 2026-09-22. [All changes since v0.1.8](https://github.com/virtues-os/virtues/compare/v0.1.8...v0.1.9)

```sh
sudo virtues upgrade --version v0.1.9
```

## New

- **Projects.** Notebooks are now called Projects. Your existing notebooks carry over as they are.
- **Recently deleted.** Deleting a chat, page, or project moves it to Recently deleted. It stays there for 30 days, and you can restore it until then.
- **Undo.** Archive and delete tell you what they did and give you an undo, so a delete you can reverse no longer asks you to confirm first.
- **Archiving projects.** An archived project leaves your working view and keeps everything in it.
- **Home.** The rail is reorganized around Home, which lists your chats and pages together under Today and Recent. Sources sits below Drive, and a Setup tile on the rail takes you back to getting started.
- **Better ⌘K results.** Search ranks results within each group by what you open often and recently.
- **A turns index in chat.** Your messages in a long chat are listed down the left edge, so you can jump back to any of them.
- **Answers show their sources.** When the assistant answers a question about your life, it says what the answer rests on. A chart cites the query that produced it.

## Changed

- **Pages editor.** Formatting marks appear only where you're typing. Selections show over colored backgrounds, lists indent from their real depth, and tables handle pipes and scroll sideways. `==highlight==` works.
- **Chat recovers from failed tool calls.** When the assistant repeats a tool call that already failed, your server refuses it. After four failures in a row, that tool is closed for the rest of the turn. A failure the assistant recovered from appears in its thinking, not as an error in the reply.
- **Your own AI endpoint.** You can set your credential's context window, and your server measures against it when it shortens a long chat.
- **Fewer wrong queries.** The assistant now sees every table's real columns, so it stops guessing column names. A query that runs past 25 seconds is stopped.

## Fixed

- Restoring a deleted folder in Drive gives back everything the delete removed.
- A bookmark found in search opens the bookmark, not its database row.
- Opening any bookmark's detail page no longer returns "not found".
- A day with sleep cycles can be written up again.
- Stop frees the chat for your next message right away, and a message your server turns away goes back to the composer.
- A permission you told chat to remember can be read back.
- On the Mac, Safari access is its own permission, and the Mac app no longer reports it as working when it isn't.

## Under the hood

- iroh updated from 1.1.0 to 1.2.0, which replaces the DNS resolver.
