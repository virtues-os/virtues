## Default Permission

Default permissions for the reach plugin

#### This default permission set includes the following:

- `allow-pair`
- `allow-reach-status`
- `allow-forget`
- `allow-discover`
- `allow-provision-open`
- `allow-provision-networks`
- `allow-provision-join`
- `allow-improv-discover`
- `allow-improv-claim`
- `allow-improv-wifi-scan`
- `allow-improv-provision`
- `allow-improv-pair`
- `allow-improv-link-code`
- `allow-improv-pair-code`
- `allow-improv-disconnect`
- `allow-outbox-stats`
- `allow-drain-now`
- `allow-radio-stats`
